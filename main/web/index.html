Rules

A rule drives a range of values. In open mode, applying one adds storage for it automatically. In strict mode, it must sit inside blocks. Addresses without a rule keep their value. Static values are set once, while random, sine and square values update continuously. Addresses omit the 0x, 1x, 3x or 4x prefix: 3001 is wire address 3000. Click a rule to load it.
